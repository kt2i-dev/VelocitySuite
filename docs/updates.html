Recent updates

What’s new or different in the standard, newest first. Check here before building or reviewing a screen.

11/16/2026

  • Theme: the design conventions. Every screen uses the shared app-* classes and --app-* tokens; no per-screen classes, inline styles, literal colors or !important. Lists the tokens and shared classes, how to choose them, the legacy class families being migrated, and the checks before saving the stylesheet.
  • Button standard: buttons are now app-btn with app-btn-primary, app-btn-outline or app-btn-danger (replacing btn, btn-primary and btn-delete). Row actions are app-icon-link.
  • Custom widgets: each block lists the shared classes it’s built from.
  • Review checklist is up: styling, layout and fields, buttons, dates and status, behavior, and stylesheet checks.
  • Detail and edit screens are being merged into one screen per record type with an edit mode. The Details/Edit Screen Template stays coming soon until the NCRDetailScreen pilot is finished.

11/15/2026

  • Decided: left side menu, MM/dd/yyyy dates, Phosphor 2.0 icons. The Button standard now gives Phosphor icon names, and DateFormat shows MM/dd/yyyy.
  • Button standard: three styles (btn, btn-primary, and a new custom btn-delete for Delete only), one primary per screen, every button’s icon, class and place, the reusable button blocks, and how this differs from the mockups.
  • Custom widgets: DateFormat, RecordHeader and the filter buttons carried over from LifeView; the shared components from the UI/UX specification (StatusBadge, WorkflowStepper, ActivityTimeline, Attachments, ActionList, ApprovalPanel, RelatedRecords, ImpactSummary); the AI Assistant Panel and room for agents.
  • AI agents: each sector page has an AI agents section (the agentic item from the bottom of each MoM column), Quality Event & Corrective Action Management has Quality Assistant and Quality agents tiles, and the start page has an AI agents standard. All coming soon.
  • Site started for the Velocity Suite for Manufacturing. The start page lists the standards (About, Button standard, Details/Edit Screen Template, Custom widgets), the five sectors, the review checklist and these updates. Pages without enough detail yet show as Coming soon.
  • Five sectors, each with its own page listing its solutions: Quality / Engineering, Supply Chain / Logistics, Production / Maintenance, Safety / Environment and Workforce / Training. Supplier Portal and Spare Parts are in progress; the rest are coming soon.
  • Quality Event & Corrective Action Management (CAPA / SCAR / MRB / NCR) is the first solution: its About page (lifecycles, business rules, Lot Trace, AI assistant, roles, demo scenario, prototype scope, and where the source documents disagree), its data model, and its twelve screens (coming soon).
  • Everything here is drawn from the solution documents: the solution overview deck, executive summary, solution brief, case study, functional specification and UI/UX specification.

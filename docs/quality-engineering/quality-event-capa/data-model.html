Data model

The entities in the OutSystems module VS_MFG_QualityAssurance. * marks a mandatory attribute. Every entity also has an Id (a Long Integer, except the static entities). Generated by tools/build_data_model.py: edit that, not this page.

Relationships

  • A QualityEvent has NCRs, CAPAs, SCARs, quality holds, files, actions and audit entries.
  • An NCR has MRB reviews, containment actions, root causes and files.
  • An MRBReview has MRB dispositions.
  • A CAPA has actions, effectiveness checks, root causes and files.
  • A SCAR has 8D responses.
  • A RootCause has root cause analysis (“Why”) rows.
  • A Lot links to its genealogy (parents and children), serial numbers and shipments, and is referenced by NCRs, Quality Events and quality holds.
  • A Supplier links to materials, purchase orders, receipts and contacts.
  • A Product links to Material, WorkOrder and Lot.
  • The system User and Role entities are referenced read-only.

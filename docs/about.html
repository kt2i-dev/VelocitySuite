About Velocity Suite

Reusable starting points, built on OutSystems by KT2i and tailored to each customer.

What it is

Velocity Suite is a set of ready-made applications, each one aimed at a workflow that falls between a customer’s core systems: the work an ERP or MES leaves people coordinating by email and spreadsheets. Each application is a working starting point rather than a blank build, so a customer sees their process running early and the project shapes it from there.

How each application is delivered

  • Integrate with the customer’s ERP, MES and existing data sources.
  • Adapt the screens, rules and approvals to the customer’s site and process.
  • Expand workflow by workflow as each one proves its value.

How it’s organized

The suite is grouped by sector (an industry, such as Manufacturing). Each sector has its own applications, and every application is built to the same standards: one button standard, one set of custom widgets, and one detail-screen template. That keeps screens consistent from application to application, so a developer who has built one can build the next.
